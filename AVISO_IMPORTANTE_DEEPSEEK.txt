🔴 PROBLEMA CORRIGIDO!

Você estava usando o modelo 'deepseek-chat' que NÃO suporta análise
de imagens. Por isso, todos os pedidos com fotos anexadas falhavam.

═══════════════════════════════════════════════════════════════════════

✅ SOLUÇÃO: Use o modelo com suporte a visão

Abra o arquivo .env e mude a linha LLM_MODEL:

┌───────────────────────────────────────────────────────────────────┐
│ ❌ ANTES (não funciona com imagens):                              │
│                                                                   │
│   LLM_PROVIDER=deepseek                                           │
│   LLM_MODEL=deepseek-chat                                         │
│   DEEPSEEK_API_KEY=sk-...                                         │
└───────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────┐
│ ✅ AGORA (funciona com texto + imagens):                          │
│                                                                   │
│   LLM_PROVIDER=deepseek                                           │
│   LLM_MODEL=deepseek-vl-7b-chat                                   │
│   DEEPSEEK_API_KEY=sk-...                                         │
└───────────────────────────────────────────────────────────────────┘

═══════════════════════════════════════════════════════════════════════
